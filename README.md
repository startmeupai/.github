# Start Me Up .AI Community Defaults

This repository provides the public profile and default community-health files
for the [Start Me Up .AI GitHub organization](https://github.com/startmeupai).

Repositories can override these defaults with project-specific contribution,
security, support, issue, and pull-request guidance.

The organization profile is maintained in [`profile/README.md`](profile/README.md).
