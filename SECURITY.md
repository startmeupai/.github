# Security Policy

## Reporting a Vulnerability

Use the affected repository's Security tab and private vulnerability reporting
when available. Do not open a public issue containing credentials, exploit
details, personal data, or private repository content.

If private reporting is unavailable, email `contact@startmeup.ai` with
`[SECURITY]` and the repository name in the subject. Include the affected
version, reproduction steps, expected impact, and any suggested mitigation. Do
not include live credentials.

We aim to acknowledge a complete report within five business days and will
coordinate disclosure after a fix is available.

## Supported Versions

Consult the affected repository's own security policy or release documentation.
In general, fixes target the default branch and latest supported release.
