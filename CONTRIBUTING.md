# Contributing

Thank you for contributing to a Start Me Up .AI open-source project.

## Standard Workflow

1. Search existing issues and pull requests.
2. Open an issue before a large or compatibility-changing proposal.
3. Fork the repository and create a focused branch.
4. Follow the repository's local setup and verification instructions.
5. Keep the change scoped and add tests or documentation where applicable.
6. Open a pull request and list only checks that actually ran.
7. Address CI and maintainer feedback.

Contributors do not need organization membership or direct write access.
Repositories may define additional requirements in their own
`CONTRIBUTING.md`.

## Safety

Do not include credentials, private code, customer data, private domains, or
vulnerability details in public issues or pull requests. Follow the repository's
security policy for private reporting.
